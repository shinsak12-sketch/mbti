# 🎁 보상 MBTI — 직원 교육 아이스브레이킹용

직원 교육의 아이스브레이킹 시간에 바로 쓸 수 있는 **"나를 춤추게 하는 보상 유형" 성격 테스트**입니다.
설치·서버 없이 `index.html` 파일 하나로 동작하며, 참가자들이 각자 휴대폰으로 열어 12문항에 답하면 16가지 보상 성향 중 하나가 나옵니다.

## ✨ 특징

- **파일 하나**로 완결 — 인터넷 연결 없이도 브라우저만 있으면 동작
- **모바일 최적화** — 참가자들이 각자 폰으로 참여
- **12문항 · 약 1분** — 아이스브레이킹에 딱 맞는 분량
- **매니저 팁 포함** — 결과마다 "이 사람을 춤추게 하려면" 가이드가 있어 리더 교육에도 활용 가능
- **결과 공유** — 결과 문구 복사 / 화면 캡처로 팀 채팅방 공유

## 🧭 보상 성향 4개 축 (2×2×2×2 = 16유형)

| 축 | 한쪽 | 다른 쪽 |
|----|------|---------|
| **형태** | 실속형(M) · 돈/물질 | 가치형(E) · 경험/의미 |
| **타이밍** | 즉시형(I) · 바로바로 | 축적형(A) · 모아서 크게 |
| **대상** | 개인형(S) · 나부터 | 팀형(T) · 함께 |
| **방식** | 스포트라이트형(P) · 공개 | 은근형(Q) · 조용히 |

## ▶️ 사용 방법

1. `index.html`을 브라우저에서 엽니다 (더블클릭 또는 드래그).
2. 사내망/사내 페이지에 올려 QR 코드로 공유하면 참가자들이 폰으로 접속하기 편합니다.
3. "테스트 시작하기" → 12문항 응답 → 결과 확인.

### 진행자 팁 (아이스브레이킹 흐름 예시)

1. **개별 진행 (2~3분)**: 각자 테스트하고 자기 유형 확인.
2. **자기소개 라운드**: "저는 OO형이고, 이런 보상에 심장이 뛴대요!" 한 줄씩 공유.
3. **팀 매칭 토크**: 결과의 *환상의 짝꿍 / 티키타카 필요* 를 보며 "우리 팀엔 어떤 유형이 많나?" 이야기.
4. **리더 교육 연계**: 매니저 팁을 함께 읽고 "우리 팀원을 어떻게 동기부여할까?" 토론.

> 이 테스트는 재미와 상호 이해를 위한 활동이며, 실제 심리검사(MBTI®)와는 무관합니다.

## 🛠️ 커스터마이징

모든 내용이 `index.html` 안에 있어 수정이 쉽습니다.

- **질문 수정/추가**: `QUESTIONS` 배열 (각 문항의 `k` 값이 축 글자 M/E/I/A/S/T/P/Q).
- **유형 설명 수정**: `TYPES` 객체의 각 코드(예: `MISP`)별 `n`(이름), `tag`, `desc`, `loves`, `tip`, `good`, `bad`.
- **색상/디자인**: 상단 `<style>`의 `:root` 변수(`--bg1`, `--accent` 등).

> 각 축은 3문항이라 동점이 없어 항상 한 유형으로 결정됩니다. 문항 수를 바꿀 때는 축별 홀수 문항을 권장합니다.
